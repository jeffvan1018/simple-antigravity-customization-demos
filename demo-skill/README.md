# Skill Demo

This directory contains a custom skill (`.agents/skills/dotnet-solution-scaffold/`) that scaffolds a .NET solution with an opinionated `src/` and `test/` layout.

**Prerequisite:** .NET SDK (`dotnet`)

Open this directory in your harness and ask the agent to create a new .NET solution:

```bash
agy -p "Create a new solution for my pirate supply company"
```
