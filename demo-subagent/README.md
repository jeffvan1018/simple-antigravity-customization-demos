# Subagent Demo

This directory defines a custom subagent (`.agents/agents/legacy-dotnet-sme/agent.md`) configured as a Legacy .NET Framework (1.0–4.8) Subject Matter Expert.

Open this directory in your harness and run `/agents` to view the subagent, or invoke it from the default agent:

```bash
agy -p "tell me about migrating from dotnet 1.0 to 2.0"
```
